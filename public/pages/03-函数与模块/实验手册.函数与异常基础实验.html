实验手册.函数与异常基础实验

函数与异常基础实验手册

本手册依据第 03 章《函数与模块》与第 04 章《异常处理》的讲义（第 14、16、21 讲）编制，是一份纯上机练习册。

手册由实验总则、九个实验单元和三个附录构成。九个单元里的题目全部是动手写代码的操作题，没有需要背诵的概念判断、程序阅读和填空题——每道题都给出明确的步骤要求和一次运行示例，你只要把代码写出来、跑出结果、和示例对照，就算完成了这道题。做完一遍不过瘾的，可以把示例里的数据改一改再跑一次，看看会出什么差别。

本手册与《实验3.函数与模块综合实验》《实验4.文件与异常综合实验》互补：前者侧重单个知识点的反复练习，后两者侧重完整案例的综合运用。

实验总则

适用范围与知识背景

对应讲义：《14.函数和模块》（定义函数、函数的参数、变量作用域、用模块管理函数、标准库中的模块和函数）、《16.函数使用进阶》（Lambda 函数、递归调用、生成器）、《21.异常处理》（异常处理机制、断言）。

前置知识：变量与基本数据类型、运算符、分支结构、循环结构（for-in 与 while）、break 与 continue、列表与字典的基本操作、random 模块、f-string 格式化输出。

未涉及内容：把函数作为参数、高阶函数、偏函数、装饰器（属于《17.函数高级应用》的提高内容），以及文件的读写操作。全部题目均可在已学知识范围内完成。

实验目的

  1. 能独立写出带参数和返回值的函数，熟练使用位置参数、关键字参数、默认参数与可变参数。
  2. 能区分局部变量与全局变量，知道什么时候该用global、什么时候该改用参数和返回值。
  3. 能把一组工具函数拆到独立的模块文件里，并用三种方式导入使用。
  4. 能写出一行式的 Lambda 表达式，并能用它配合sorted函数的key参数自定义排序规则。
  5. 能写出一个带递归出口的递归函数，并理解递归为什么比循环慢。
  6. 能写出一个生成器函数，理解"要一个算一个"的执行方式，并能用生成器处理大批量数据。
  7. 能写出完整的try...except...else...finally结构，会用raise主动抛出异常、会定义简单的自定义异常类型。
  8. 知道断言的作用与限制：断言用于检查程序内部的前提，不用于校验用户输入，并且可以被python -O关闭。
  9. 养成"先写代码、再跑结果、最后对照示例"的上机习惯，遇到差异能自己分析原因。

实验环境

  • Python 3.8 及以上版本。
  • 任意代码编辑器或 IDE（如 PyCharm、VS Code）。
  • 建议每题新建独立脚本文件，命名格式为 lab3_单元号_题号.py，例如实验一题目 1 记为 lab3_1_1.py。
  • 实验三涉及多文件，请把同一单元的模块文件放在同一个文件夹中。

实验要求与报告规范

  1. 每道题按步骤要求独立完成，先把代码写完再运行，不要边想边抄。
  2. 每道题都要跑出与"一次运行示例"一致的结果；如果结果不一致，先自己找出原因并记录下来。
  3. 代码规范：函数名和变量名见名知意，关键函数写文档字符串，必要的逻辑写注释；不要把一行写得太长。
  4. 含随机数的题目连续运行三次，在报告中记录三次结果，并用一句话说明结果不同的原因。
  5. 拓展任务有余力再做，做不出来也不影响本单元的完成情况。
  6. 评定建议：按功能完成度、代码规范性、与示例输出一致性评定；拓展任务完成得好的酌情加分。

实验一 函数的定义与参数

（对应讲义 14）

题目 1.1 温度转换与数值工具

考查知识点：函数定义、参数与返回值、文档字符串、f-string 格式化输出。

  1. 编写函数c2f(celsius)，把摄氏温度转换成华氏温度（公式：华氏 = 摄氏 × 9 / 5 + 32）；再编写f2c(fahrenheit)，把华氏温度转换成摄氏温度（公式：摄氏 = (华氏 − 32) × 5 / 9）。输出 0、100、37.5 三个温度值的双向转换结果。
  2. 编写函数max3(a, b, c)，返回三个数中最大的一个（提示：可以用一次if判断，也可以调用内置函数max）。
  3. 编写函数is_leap(year)，判断某一年是不是闰年：年份能被 400 整除，或者能被 4 整除但不能被 100 整除时，是闰年。输出 2000、1900、2024、2023 年的判断结果。
  4. 编写函数total_price(price, count)，返回购买 count 件单价为 price 的商品的总价，并在主程序中用 f-string 输出形如"总价：xx.xx 元"的文本（提示：格式化小数用:.2f）。

一次运行示例：

text
0.0 摄氏度 = 32.0 华氏度
100.0 摄氏度 = 212.0 华氏度
37.5 摄氏度 = 99.5 华氏度
最大值： 42
2000 年是闰年： True
1900 年是闰年： False
2024 年是闰年： True
2023 年是闰年： False
总价： 128.00 元

题目 1.2 成绩统计小工具

考查知识点：函数拆分、列表遍历、*args可变参数、返回值的多种形式。

  1. 编写函数total_score(scores)，返回成绩列表的总分（列表为空时返回 0）。
  2. 编写函数average(scores)，返回成绩列表的平均分（保留 1 位小数，列表为空时返回 0）。
  3. 编写函数highest(scores)，返回成绩列表中的最高分。
  4. 编写函数report(scores)，把上面三个结果整理成一个字典返回，键分别是'total'、'average'、'highest'，然后在主程序中打印这个字典。
  5. 拓展任务：再写一个grade_of(score)函数，按 90/80/70/60 分档返回'A'/'B'/'C'/'D'/'F'，并让report多返回一个键'grades'，值是每个成绩对应的等级的列表。

用成绩列表[95, 82, 80]测试，一次运行示例：

text
总分： 257
平均分： 85.7
最高分： 95
统计结果： {'total': 257, 'average': 85.7, 'highest': 95}

实验二 变量作用域

（对应讲义 14）

题目 2.1 文本统计工具

考查知识点：局部变量与全局变量的分工、字典的计数用法、函数的返回值。

  1. 编写函数count_words(sentence)，用空格分割句子，统计每个单词出现的次数，返回一个字典（提示：sentence.split()可以按空白分割字符串；字典的计数写法见《13.常用数据结构之字典》）。
  2. 编写函数longest(words)，返回一个列表中最长的单词（提示：内置函数max可以配合key参数使用，也可以自己写循环比较长度）。
  3. 编写函数merge_counters(counter1, counter2)，把两个计数字典合并成一个：同一个键的计数相加，不同的键直接合并。
  4. 拓展任务：把第 3 题的结果再保存到一个全局变量total_counter中，并在主程序中打印出来，观察它与函数内部临时变量的区别。

一次运行示例：

text
{'Python': 2, 'is': 1, 'fun': 1}
最长单词： Python
合并后： {'Python': 3, 'is': 1, 'fun': 1}
全局累计： {'Python': 3, 'is': 1, 'fun': 1}

思考：第 4 步中，如果把total_counter = merge_counters(...)这一行放到函数内部去写，结果有什么不同？

题目 2.2 同一个功能的两种写法

考查知识点：全局变量与局部变量的差别、global关键字、"参数传入、返回值传出"的编程习惯。

  1. 先用全局变量的写法实现"累计购物金额"：定义一个全局变量total，再写一个函数add_price(price)，在函数中用global把价格累加到total上，并打印当前累计金额。
  2. 再用不用全局变量的写法实现同样的功能：函数add_price2(total, price)只负责把金额加上并返回新的总额，由主程序拿返回值重新赋值。
  3. 把两种写法的代码都写出来，运行后对比输出，说说它们分别适用于什么场景。
  4. 拓展任务：把第 1 种写法改成一个"不依赖全局变量"的版本，但仍然希望累计金额能在函数之外保留下来，看看该怎么写。

一次运行示例：

text
写法一（用 global）：
当前累计金额： 35
当前累计金额： 83
函数外的 total = 83
写法二（用参数和返回值）：
当前累计金额： 35
当前累计金额： 83
函数外的 total = 83

思考：两种写法输出的最终结果完全一样，为什么实际开发中还是更推荐第二种？

实验三 模块与标准库

（对应讲义 14）

题目 3.1 把工具函数拆成模块

考查知识点：模块的划分、import与from...import...的用法、模块之间的协作。

  1. 新建文件temperature.py，把题目 1.1 的c2f和f2c两个函数放进去，函数体保持不变。
  2. 新建文件main.py，用import temperature的方式导入，调用temperature.c2f(100)并输出结果。
  3. 在main.py中再用from temperature import c2f导入一次，调用c2f(0)并输出结果。
  4. 再新建一个文件tools.py，其中定义一个函数average(scores)用于计算平均分（列表为空时返回 0），然后在main.py中用from tools import average导入它，输出average([80, 90, 100])的结果。
  5. 拓展任务：把main.py拆成main.py（调用方）和utils.py（被调用方）两个文件，把上面三个函数全部放进utils.py，体会"按职责拆分模块"的好处。

一次运行示例：

text
100.0 摄氏度 = 212.0 华氏度
0.0 摄氏度 = 32.0 华氏度
平均分： 90.0

思考：如果main.py和utils.py都在同一个文件夹下，为什么import utils就能直接找到它？

题目 3.2 标准库初体验

考查知识点：标准库模块的导入方式、random、math、string、time模块的常用函数。

  1. 用string模块的digits和ascii_uppercase拼出"数字 + 大写字母"的字符集，用random.choices生成一个 4 位随机验证码并输出。
  2. 用math.sqrt计算 2 的平方根，用math.pi输出圆周率（都保留 4 位小数）。
  3. 用time.time()测量"把 1 到 1000000 求和"这段代码花了多少秒，并输出耗时。
  4. 用random.shuffle把列表[1, 2, 3, 4, 5]打乱后输出。
  5. 拓展任务：把上面四段代码分别写成四个独立的函数，再写一个main()函数依次调用它们。

一次运行示例（随机部分每次可能不同）：

text
随机验证码： K7M2
2 的平方根： 1.4142
圆周率： 3.1416
求和耗时： 0.0021 秒
打乱后的列表： [3, 1, 5, 2, 4]

实验四 Lambda 函数

知识点总结

一、函数的定义、调用与返回值

  • 用 def 定义函数：def 函数名(参数列表):，行末的 : 不能漏，函数体统一缩进 4 个空格。
  • 函数体中用 return 交出结果；return 语句之后的代码不再执行；没有写 return 的函数调用后返回 None。
  • 一次调用只返回一个值，需要多个结果时返回元组或字典；一个函数可以写多个 return，由不同的条件决定走哪一条。
  • 定义时写的名字叫形参，调用时传入的值叫实参；调用函数必须写括号并给出实参。
  • 关键函数在函数体第一行写文档字符串（"""..."""），说明用途、参数和返回值。

二、函数参数的常用形式

  • 位置参数：按顺序一一对应，最常用。
  • 关键字参数：调用时写成 名字=值，顺序可以与定义不同，可读性更好。
  • 默认参数：定义时写成 def f(x, step=1)，调用时可以不传；有默认值的参数必须放在无默认值参数的后面。
  • 可变位置参数 *args：把多余的位置实参收集成一个元组。
  • 可变关键字参数 **kwargs：把多余的关键字实参收集成一个字典。
  • 调用时可用 * 和 ** 拆开传参：f(*nums) 把列表或元组拆成位置实参，f(**info) 把字典拆成关键字实参。

三、变量作用域

  • 函数内部创建、函数外部无法直接访问的变量是局部变量；在函数外部定义的变量是全局变量，函数内可以读取。
  • 函数内要修改全局变量，必须先写 global 声明，并且 global 语句要写在函数体的最前面。
  • 更推荐"参数传入、返回值传出"：函数不依赖全局状态，才便于测试和复用。
  • 全局变量在循环中持续累加容易得到意料之外的结果，做累计时优先用返回值或可变对象参数。

四、模块与标准库

  • 模块就是一个 .py 文件；把一组工具函数放进模块，再用 import 引入。
  • 三种导入写法：import 模块名（用 模块名.函数名() 调用）、import 模块名 as 别名、from 模块名 import 函数名（直接使用函数名）。
  • 脚本所在目录会被自动加入模块搜索路径，所以同目录的模块可以直接 import。
  • 在模块文件里用 if __name__ == "__main__": 保护主程序代码，避免模块被导入时自动执行。
  • 常用标准库：math（数学函数）、random（随机数）、time（时间）、os（操作系统）、sys（解释器参数）、string（常用字符集合）；用到前先 import。

五、Lambda 函数

  • lambda 参数: 表达式 写出一行式匿名函数，返回值就是表达式的结果，不能写多条语句。
  • 典型用途是配合 sorted 的 key 参数自定义排序规则，例如 sorted(students, key=lambda s: s['score'])。
  • reverse=True 表示降序；需要多条件排序时让 key 返回元组，例如 key=lambda s: (-s['score'], s['name'])。
  • 逻辑长或需要复用时优先写命名函数；lambda 适合"只用一次、逻辑很短"的场景。

六、递归调用

  • 递归函数自己调用自己，必须有递归出口（终止条件），否则运行时会抛出 RecursionError。
  • 写法三步：先找出口，再写递推关系，最后写调用；gcd、factorial、汉诺塔是典型例子。
  • 递归比循环慢、占用更多内存（每一层调用都保留一份局部变量），能用循环解决的场景优先用循环。

七、生成器

  • 函数体中用 yield 一次产出一个值，它就是生成器函数；调用它得到生成器对象。
  • yield 的作用是"暂停并交出一个值"，return 是"结束并交出结果"，两者不能混为一谈。
  • 取值用 next(生成器) 或 for 循环；无限生成器只能用 next() 逐个取，用 for 遍历会停不下来。
  • 生成器表达式 (表达式 for 元素 in 序列) 与列表生成式写法相近，但边算边用，内存占用小，适合处理大批量数据。

八、异常处理

  • 语法结构：try 放可能出错的代码，except 捕获并处理，else 在没有异常时执行，finally 无论如何都执行。
  • except 要捕获具体的异常类型（例如 except ValueError as e:），except Exception 只作兜底，不能用它代替具体处理。
  • raise 主动抛出异常，用于把不合法的情况交给上层处理；自定义异常写成 class MyError(Exception):。
  • 常见异常：ValueError（值不合法）、TypeError（类型不匹配）、ZeroDivisionError（除零）、IndexError（下标越界）、KeyError（键不存在）、NameError（名字未定义）、FileNotFoundError（文件不存在）、ImportError（模块不存在）、StopIteration（迭代结束）、RecursionError（递归过深）。
  • 异常处理写在真正可能失败的那一步，不要用一个大 try 把整个程序包起来，否则真实错误会被掩盖。

九、断言

  • assert 条件, "提示信息"：条件为假时抛出 AssertionError，用来检查程序内部的前提。
  • 断言只用于"程序员自己的错误"，不用于校验用户输入；用户输入要用 if 判断并抛异常。
  • python -O 会关闭断言，所以关键校验不能只依赖 assert。

十、命名规则与代码风格

  • 函数名、变量名、模块名用小写加下划线（total_score、count_words）；常量用全大写（MAX_SIZE）。
  • 函数名用动词（get_score、average），返回布尔值的函数以 is_ 开头（is_leap、is_valid_score）。
  • 模块名简短且有意义（temperature.py、score_utils.py）；实验脚本按 lab3_单元号_题号.py 命名。
  • 一行只做一件事，关键逻辑写注释，关键函数写文档字符串，函数与模块之间用空行分隔。
  • 含随机数的程序每次输出可能不同，报告中要记录多次运行结果并说明原因。

十一、复习时的易错点

  • 漏写行末的 : 或缩进不一致，导致 IndentationError。
  • 把 return 写在 print 之后，函数变成"只打印不返回"。
  • 默认参数定义在无默认值参数之前，调用时报 SyntaxError。
  • 认为 global 声明可以写在函数中间——它必须位于函数体最前面。
  • 以为 import 模块名 后可以直接使用模块里的函数名，忘了写 模块名.函数名()。
  • 递归函数没有出口，运行时报 RecursionError。
  • 用 for 遍历无限生成器，程序永远停不下来。
  • except Exception 一把抓，真实错误信息被吞掉。
  • 用 assert 校验用户输入，程序加上 -O 参数后就失效。

十二、学习重点

  • 能独立写出带参数、带返回值、带文档字符串的函数，熟练使用位置参数、关键字参数、默认参数与 *args。
  • 能说清局部变量与全局变量的区别，需要共享状态时优先选择"参数传入、返回值传出"。
  • 能把工具函数拆成独立模块，用三种导入方式调用，并用 if __name__ == "__main__": 保护主程序。
  • 能用 lambda 配合 sorted(key=...) 写出单条件与多条件排序。
  • 能写出带出口的递归函数，并能解释递归比循环慢的原因。
  • 能写出发成器函数，理解 yield 与 return 的区别，能说明生成器省内存的原理。
  • 能写出完整的 try...except...else...finally 结构，能用 raise 抛异常、能定义自定义异常类。
  • 能说清断言的适用场景，并知道 python -O 会关闭断言。
